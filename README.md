# Second Bite

*A second chance for good food.*

Second Bite is a bilingual (Vietnamese and English) marketplace for genuine food surplus in Vietnam. Shops and restaurants offer edible food and ingredients they would otherwise throw away, at a discount; nearby customers reserve confirmed stock and collect it from the seller with a one-use code. The first pilot runs with the food and beverage outlets of Tasco Mall in Việt Hưng ward, Hanoi.

## State of the repository

No application code exists yet. The repository holds the product brief, the vision and roadmap, the engineering conventions, the research done before design, and the first increment: the pilot's domain model, worked through boundary discovery.
