# stats: verification matrix

Requirements of [docs/specs/stats.md](../specs/stats.md) and the checks that hold them. Paths are under `server/`.

| Requirement                                                                                                                                                                            | Check                                                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| The home, a store and a dish are read from the path with or without the locale; a bad id, an order and the cart are other                                                              | `TestPageOf` (`internal/stats/stats_test.go`)                                                                                   |
| One browser has one key a day, another key the next day; the address and the browser never run into each other                                                                         | `TestVisitorKey`                                                                                                                |
| The address is the first forwarded one, else the connection's                                                                                                                          | `TestClientAddress`                                                                                                             |
| The day is Vietnam's, past midnight there                                                                                                                                              | `TestDayOf`                                                                                                                     |
| A view keeps its page, store and source; a source out of its pattern is none; one browser is one visitor, also after a restart                                                         | `TestService` › a view keeps its page, store and source, and one browser is one visitor                                         |
| Bots, a missing User-Agent and a prefetch are not counted                                                                                                                              | `TestService` › a bot and a prefetch are not counted                                                                            |
| Salts of past days and views older than 400 days are forgotten; yesterday's views stay                                                                                                 | `TestService` › old salts and views are forgotten                                                                               |
| Through the API a view is counted without a session, with the forwarded address; a bot's is answered the same and not kept; an empty path is refused                                   | `TestService` › a page view is counted without a session (`cmd/secondbite/stats_test.go`)                                       |
| The report counts a store's views, posts and orders on their day, one browser on its page and its dish once, and every day of the range                                                | `TestService` › the report counts a store's views, posts and orders (`cmd/secondbite/report_test.go`)                           |
| A reversed range and one of 93 days are refused; customers are refused                                                                                                                 | `TestService` › the report counts a store's views, posts and orders; every admin operation refuses the signed out and customers |
| `order` counts held, collected with units and đồng, cancelled and expired orders per day and store; `offer` counts offers and units and names a dish's store; `seller` names stores    | `TestOrder` › the report counts the days (`internal/order/report_test.go`)                                                      |
| Only admins read the report                                                                                                                                                            | `TestService` › every admin operation refuses the signed out and customers (`cmd/secondbite/admin_test.go`)                     |
| The CSV starts with a byte order mark, has a row for the site on each day and one per store, the totals last, the share rounded and empty without orders, and writes a formula as text | `TestReportCSV`, `TestReportCSVOfOneStore`, `TestSafe` (`internal/stats/export_test.go`)                                        |
| Through the API the CSV is a `text/csv` attachment named by its days, with the store's name                                                                                            | `TestService` › the report counts a store's views, posts and orders                                                             |
| The web counts a customer's page with its locale and source, not an admin's or a store's own page, nor a browser a program drives                                                      | `viewOf` (`web/src/features/stats/count-view.test.ts`); `count-view.spec.ts`                                                    |
| The report page shows the cards, the bars and a row per store; a store and a sort are kept in the address; Xuất CSV downloads the file; no serious accessibility violation             | `admin-reports.spec.ts`                                                                                                         |
| `stats` reaches `offer`, `order` and `seller` only through their root packages                                                                                                         | `TestModuleBoundaries` (`internal/boundaries_test.go`)                                                                          |
